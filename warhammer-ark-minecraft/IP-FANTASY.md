# IP: Fantasy campaign analogue (not a Games Workshop / Total War clone)

This pack’s **tone references** are Warhammer Fantasy Battle / *Total War: Warhammer* and Ark-style survival. It is **not** a licensed Warhammer product, **not** a Total War mod, and **not** a 40k pack. Ship it as an **original grimdark-fantasy total-war campaign**.

Companion to [`LEGAL-NOTES.md`](LEGAL-NOTES.md): that file covers GW games-and-apps, Mojang EULA, and Wildcard/ASA. This document is the **Fantasy / Total War / campaign-branding** addendum (analogue lexicon, public title, what “winning a province” must not clone).

This is not legal advice. It is a working policy so the repo does not paint a target on itself.

---

## 1. What the rights-holders actually say

### Games Workshop — fan content vs games

GW’s published Intellectual Property Guidelines (fan-site reprint; official storefront URL returned 404 on 2026-08-31) distinguish hobby fan-fiction from **games**:

- Fan fiction / hobby books / fan sites: unofficial, non-commercial, no copied art/text, no GW logos, must say **unofficial**.
- **“Games and apps – individuals must not create computer games or apps based on our characters and settings. These are only to be created under licence from Games Workshop.”**
- Fan films/animations: licence only.
- Zero-tolerance list includes unauthorised trademarks and counterfeit/imitation models.

Sources:

- “Games Workshop Intellectual Property Guidelines,” 40k Fan reprint — https://40kfan.com/games-workshop-intellectual-property-guidelines/ — accessed 2026-08-31  
- Community discussion of the games/apps clause — https://rpg.stackexchange.com/questions/204173/non-commercial-rpgs-in-the-40k-universe — accessed 2026-08-31  
- Enforcement example (Warhammer Armies Project asked to strip GW art/text): “Warhammer Armies Project nixed after alleged GW legal claim,” Wargamer — https://www.wargamer.com/warhammer-armies-project-discontinued — accessed 2026-08-31  

A Minecraft **modpack** is a computer game distribution. Treating this repo as “just fan fiction” is not a shield. **Do not ship GW names, heraldry, unit sculpts, copied lore text, or trademarks.**

### Creative Assembly / Total War

CA allows *Total War: WARHAMMER* **workshop mods** under that game’s EULA: no third-party IP, no offensive treatment of the Fantasy setting, **Fantasy only** (no 40k / Age of Sigmar crossover in those mods), no charging for mods.

Sources:

- “Content Creators,” Total War Wiki — https://wiki.totalwar.com/w/Content_Creators.html — accessed 2026-08-31  

That permission is **for mods inside Total War**, not for a Minecraft pack that reimplements the campaign map. Do not copy TW UI art, faction logos, advisor VO, or campaign-map assets.

### 40k

Out of scope. No Adeptus, no bolters, no aquila, no “in the grim darkness of the far future.” If a survival mod looks sci-fi, keep it out of the **Fantasy campaign** slice.

## 2. Working rule for this repo

| Do | Don’t |
| --- | --- |
| Original world name, original faction names, original flags | Empire / Bretonnia / Kislev / Skaven / names of Elector Counts as *product identity* |
| “Inspired by grimdark Renaissance-fantasy total war” in README | “Unofficial Warhammer Minecraft” as a store title |
| New heraldry (no imperial cross-that-is-a-GW-mark, no eight-pointed Chaos star as a *logo*) | Tracing GW miniature silhouettes or TW loading-screen art |
| Mechanics analogues (provinces, sieges, grudges-as-quests, corruption-as-biome) | Copied army lists, copied spell names, copied unique weapons |
| Cite TW/WH as *designer tone-refs* in internal docs | Put those trademarks on CurseForge/Modrinth search tags |

Internal design docs (like `CAMPAIGN.md`) may mention tone-refs in parentheses so pack builders know the *feel*. **In-game lang files, quest text, item names, and public README must use analogue names only.**

## 3. Recommended public branding

**Primary:** original setting name. Candidates that fit this repo without claiming GW:

- **Rallous Marches** / **Rallous: The Grim March** (matches `rallous-system`)
- **Frontier Marches** (matches existing “Warhammer Frontier” *working* nickname — **do not use “Warhammer” in the public pack title**)
- **The Old Marches: a grimdark fantasy total-war campaign**

**Subtitle formula:** “An unofficial original-setting Minecraft campaign: open-world warband survival with provincial war.”

**Avoid:** Warhammer, Sigmar, Age of Sigmar, Old World (as a product title — it is GW’s tabletop line), Total War, Creative Assembly, Games Workshop, White Dwarf, any faction names from army books.

The root README currently says “Warhammer Frontier.” Treat that as an **internal working title**. Public pack name should drop “Warhammer.”

## 5. Assets, monetization, distribution

- Download mods only from CurseForge, Modrinth, or author GitHub. No jar dumps in git. No redistributed GW art “for flavor.”
- Original quest text and original skins only. Commission original heraldry.
- **Do not monetize** a GW-based version. Even an original analogue pack should stay clean of stolen art; if you ever sell a server cosmetic shop, it must be 100% original IP.
- If GW or CA ever offers a licence, that is a different product. This repo is the analogue.
