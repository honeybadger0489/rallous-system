# Rallous Warhammer Fantasy — play this

**Minecraft 1.20.1 + Forge 47.4.10.** Private friends pack. Import locally; do not upload.

Mods are the **engine**. This zip’s `overrides/` are the **Old World**: a Total War: Warhammer geography campaign (FTB Quests), six named lords with letters, advancements, commission recipes, Recruits/LSO glue, and a lang pack that calls troops Electors / State Troopers / Waaagh. We borrowed Recruits, Iron’s, Fossils, Epic Fight, Terralith, Sons of the Empire kits, grim resource packs. We did **not** sculpt Total War models — graphics are Faithful 32x + Grimdark Battlepack + Grimdark Sky + Gothic font + Complementary Unbound + Sons of the Empire armor on Steve-like / villager bodies.

Import **`warhammer-ark-minecraft/dist/rallous-warhammer-fantasy-0.2.2.zip`** as a **new** CurseForge profile (do not update 0.2.1). Java 17, 8 GB RAM. New world: Survival, Hard, cheats ON. Terralith stays default. Shaders/packs are pre-selected; add **Rallous Continuity** if lang still says “Recruit”.

A war council (Karl Franz, Grimgor Ironhide, Mannfred von Carstein, Thorgrim Grudgebearer, Katarin, Archaon) spawns near you on first join. Trade an emerald for a letter. Quest book **`` ` ``**. If the court is missing: `/function rallous_old_world:summon_lords`.

## Smoke test (~10 steps)

The book’s identity is the **campaign** (Reikland → Border Princes → Sylvania → Worlds Edge → Kislev → Chaos Wastes). This list is only boot:

1. **Look** — grim sky, gothic font, Unbound shader, thirst/temp widgets.
2. **Body** — sprint, drink, sun vs shade; thirst and temperature move.
3. **Steel** — sword, `V` combat mode, guard.
4. **Town** — map `M`, walk a Towns-and-Towers settlement, guards on patrol.
5. **Host** — hire a Recruits soldier (State Trooper); follow command.
6. **Diplomacy** — Faction Ally/Enemy; OPAC party; open Vassal UI.
7. **Magic** — Iron’s book in Curios; `R` spell wheel; fire / ice / holy / blood.
8. **Beast** — Fossils loop or Tameable Beasts; a living creature you own.
9. **Fight** — night or dungeon with the host, combat mode on.
10. **Plate** — any Sons of the Empire kit. Then open chapter **I. Reikland** and take Karl’s letter.
